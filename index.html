KeePass Drive Backup

A personal desktop setup that uses rclone to back up an encrypted KeePass database to its owner’s Google Drive.

How it works

KeePassXC saves the password database locally in encrypted KDBX format. A scheduled task copies that encrypted file to a dedicated Google Drive folder and keeps older versions for recovery.

Google authorization allows the local rclone process to read and write backup files. The website itself does not sign you in, receive your database, or hold your Google credentials.

For personal use.

This is an informational page for a privately operated backup configuration, not a public password-management service.

Privacy and contact

Read the privacy policy for details about Google access and storage. Questions about this configuration can be raised through the project’s issue tracker. Never post passwords, databases, tokens, or other private information there.
