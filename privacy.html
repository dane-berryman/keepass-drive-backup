Privacy policy

Last updated: 31 October 2026.

Purpose and operator

KeePass Drive Backup is a personal backup configuration operated by the owner of this project for their own password database. It uses KeePassXC, rclone, and Google Drive.

Google data accessed and use

The desktop backup process requests Google Drive access to locate its backup folder, upload the encrypted KDBX database, verify uploaded files, and retain or restore backup versions. The configured Google Drive permission may allow broader Drive access; the scheduled backup is configured to operate on its dedicated KeePass folder.

Google account authorization information and access tokens are used only to authenticate the local rclone process. This website does not receive them. The database’s master passphrase is not required by the backup process.

Storage, sharing, and retention

Encrypted database copies are stored on the owner’s computer and in the owner’s Google Drive. OAuth credentials and tokens are stored locally in rclone’s configuration. Older backup versions remain until the owner deletes them. Google processes files and account data under its own policies.

The operator does not sell Google user data, use it for advertising, or use it to train AI models. Backup data is not sent to the website, GitHub repository, or an operator-hosted application server. Google user data is used only to provide the backup function, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

Your controls

The owner can stop the scheduled backup, remove local credentials, revoke the app’s access in Google Account permissions, and delete local or Drive backups. Revoking access stops future transfers; existing backup copies must be deleted separately.

Website hosting

This is a static website with no forms, advertising, analytics scripts, or application cookies. GitHub Pages may process visitor connection information, including IP addresses, under the GitHub Privacy Statement.

Questions and changes

Contact the project owner through the project’s issue tracker. Do not include sensitive information in public issues. Changes to this policy will be published here with an updated date.
